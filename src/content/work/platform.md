# Fenyx Platform - Customer inventory management

Platform for employees and fenyx customers to login, view and manage their organisation 
- multiple office locations per org
- floors & rooms per location
- furniture model catalog
- each physical item existing in a room and its condition
- client organization members, with 5 different auth access levels
- German & English i18n - custom implementation loading only keys needed



## Stack :

- react
- tanstack-start
- tanstack-query
- supabase
- tailwind
