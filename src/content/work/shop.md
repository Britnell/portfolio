# Fenyx Shop - Closing Office Sales 

- Web shop for employees to view all the items at the company office sale, and buy / reserve items.
- "Reserved shopping-cart system" - where items are 'reserved' for a user as soon as they are added to shopping cart, to avoid collisions. Customers then have 5 minutes to checkout reserved items.
- book pick-up slots for organized execution
- Max number of items per employee
- shop only accessible to company employees
- German & English i18n - custom implementation loading only keys needed
- fenyx dashboard to manage sale

## Stack :

- react
- tanstack-start
- tanstack-query
- supabase
- tailwind
- calendly
