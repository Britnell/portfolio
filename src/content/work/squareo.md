# squareo

My first font! Geometric almost-mono font (except I), where all letters are square, embellished with the same triangles, so the words and lines turn into a geometric pattern. But still vaguely readable.

- simply drawn as svg in inkscape
- converted to font with custom script for fontforge
- special kerning for AV
- https://github.com/Britnell/squareo
