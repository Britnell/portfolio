# Websecurity - Blog & demo

I was teaching myself some fundamentals of web-security and decided to write a blog to:
- better learn the content by writing up a blog explaining concepts
- build simple demos to practice and use these
- see the different principles in action

## Stack :
Built with astro, because I love astro for static sites, and also its great at server rendering and demo-ing the principles in close to Vanilla js on native Response and Headers objects
